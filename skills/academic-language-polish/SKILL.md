# Academic Language Polish / 学术语言润色

**Status / 状态:** v0.1.0 draft

## Use / 适用场景

用于降低机器翻译感、拆分长句、统一术语、改善逻辑衔接和保留学术语气。

## Boundaries / 边界

不新增事实、文献、数据、因果关系或作者观点。不把“像人写的”当成正确性证明，不模仿特定作者以规避署名或版权问题。

## Inputs and workflow / 输入与流程

输入原文、研究领域、目标读者、保留术语和修改范围。先识别事实与主张，再逐句润色，最后列出可能改变含义的修改并要求作者核对。

## Output / 输出

返回修改稿、关键修改理由、术语表、主张变化警告和待作者确认项。信息不足时保留原意并标记无法判断之处。

## Source / 来源

根据用户提供的 humanizer 类截图整理，未复制其原文或宣传语。

## English

Polish academic prose for clarity and naturalness while preserving meaning, evidence, terminology, and authorship. Do not add facts or imitate a specific author.
