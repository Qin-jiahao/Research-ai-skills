# Multi-agent Research Review / 多角色科研审查

**Status / 状态:** v0.1.0 draft

## Purpose / 用途

把复杂科研任务拆给不同审查角色，例如研究设计、统计、代码、图表和写作，并汇总为可追溯意见。

## Boundaries / 边界

多个 Agent 的一致意见不等于事实。角色不能共享未经核验的假设；最终结论必须回到原始数据、代码、文献和研究设计。

## Required inputs / 必需输入

任务范围、已有材料、角色定义、输出格式、冲突处理规则和人工确认节点。

## Workflow / 工作流程

先定义问题和证据；再分配角色；各角色独立指出证据、风险和不确定性；汇总器只整合可追溯意见；对冲突保留不同判断；最后由研究者确认行动。

## Output and checks / 输出与检查

输出角色意见表、共同结论、分歧、证据链接、待核验事项和行动清单。检查是否出现重复推测、角色越权、虚构共识或把建议写成已完成。

## Source / 来源

根据用户提供的多角色讨论截图独立整理，未直接复制其宣传性表述。

## English

Use independent role reports, explicit evidence, conflict records, and human confirmation. Consensus among agents is not evidence.
