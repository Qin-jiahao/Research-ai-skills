# Figure Generation

> Status: draft. Generated figures require visual and data-level verification.

## Purpose

支持科研图表需求分析、图形规范制定和可编辑图形生成流程设计。它不能替代对原始数据、统计结果和图注的核对。

## Required inputs / 所需输入

数据字段、统计结果、图形目的、目标读者、坐标单位、分组方式、显著性标记和输出格式。

## Workflow / 工作流程

1. 明确图形要表达的比较或关系。
2. 检查数据字段、单位和统计摘要。
3. 选择合适的图形类型和视觉编码。
4. 规定图例、坐标、误差线、样本量和图注。
5. 输出可编辑图形方案，并列出需要核验的项目。

## English

This Skill supports figure requirements, graphical specifications, and editable-figure workflows. It does not replace verification of raw data, statistical results, or figure captions.

### Required inputs and workflow

Provide data fields, statistical summaries, the figure purpose, audience, units, grouping, significance notation, and output format. Define the intended comparison, verify fields and units, choose an appropriate chart and visual encoding, specify legends, axes, uncertainty, sample size, and captions, and return an editable specification with verification items.
