# Statistical Analysis

> Status: draft. Statistical decisions require the original design and data context.

## Purpose

根据研究设计和数据类型辅助选择统计方法，并检查结果解释。它不能仅凭一张结果表断定因果关系或统计有效性。

## Required inputs / 所需输入

研究设计、变量类型、样本量、分组和配对关系、缺失值、批次因素、预设假设和分析目标。

## Workflow / 工作流程

1. 检查数据结构和研究设计是否匹配。
2. 明确估计目标、比较对象和统计假设。
3. 比较可行方法及其前提条件。
4. 输出分析方案、诊断检查、效应量和不确定性报告要求。

## English

This Skill assists with method selection and result interpretation based on study design and data type. It cannot infer causality or validity from a result table alone.

### Required inputs and workflow

Provide the design, variable types, sample size, grouping and pairing, missing values, batch factors, prespecified hypotheses, and analysis goals. Check design-data compatibility, define the estimand and comparison, evaluate candidate methods and assumptions, and report diagnostics, effect sizes, and uncertainty requirements.
