# Skills Index / Skills 索引

## 中文

本目录存放需要多步推理、明确输入和质量检查的科研工作流。每个 Skill 都提供中英文说明，使用时应同时阅读适用范围、输入要求和限制。

| Skill | 适用任务 |
| --- | --- |
| [academic-writing](academic-writing/SKILL.md) | 论文段落和章节的起草、改写与结构检查 |
| [paper-review](paper-review/SKILL.md) | 论文结构、方法、证据和表述的系统检查 |
| [literature-analysis](literature-analysis/SKILL.md) | 文献检索计划、筛选、证据表和研究空白整理 |
| [statistical-analysis](statistical-analysis/SKILL.md) | 统计方法选择、假设检查和结果解释 |
| [figure-generation](figure-generation/SKILL.md) | 科研图表需求分析、图形规范和可复现绘图计划 |

这些文件是工作流规范，不包含任何真实研究数据。模型生成的内容仍需结合原始数据、文献全文和研究设计进行核验。

## English

This directory contains research workflows that require multiple steps, explicit inputs, and quality checks. Each Skill is documented in Chinese and English. Read the scope, input requirements, and limitations before use.

| Skill | Intended use |
| --- | --- |
| [academic-writing](academic-writing/SKILL.md) | Drafting, revising, and checking research sections |
| [paper-review](paper-review/SKILL.md) | Systematic checks of structure, methods, evidence, and wording |
| [literature-analysis](literature-analysis/SKILL.md) | Search planning, screening, evidence tables, and gap mapping |
| [statistical-analysis](statistical-analysis/SKILL.md) | Method selection, assumption checks, and result interpretation |
| [figure-generation](figure-generation/SKILL.md) | Figure requirements, specifications, and reproducible plotting plans |

These files define workflows and do not contain real research data. Generated content must be checked against the original data, full-text sources, and study design.
