# Research Presentation Slide Outline Example / 科研汇报逐页大纲示例

本文件是用于展示结构的合成示例，不包含真实研究数据。示例中的研究问题、页面时长和材料状态都需要替换为用户自己的信息。

This is a synthetic example for demonstrating structure. It contains no real research data. Replace the research question, time allocation, and material status with the user's own information.

## Presentation brief / 汇报简报

- **Setting / 场景:** 8-minute lab meeting update with 2 minutes for questions / 8 分钟组会进展汇报，另有 2 分钟问答
- **Audience / 受众:** Researchers familiar with the field but not with this experiment / 了解研究领域但不了解本实验的研究人员
- **Objective / 目标:** Explain the study question, design, current evidence, and the next verification step / 说明研究问题、设计、当前证据和下一步核验工作
- **Research question / 研究问题:** Does the planned treatment change root growth under the stated stress condition? / 在给定胁迫条件下，计划中的处理是否改变根系生长？
- **Data status / 数据状态:** Sample size, effect estimate, uncertainty, and statistical test are to be provided / 样本量、效应估计、不确定性和统计检验待补充

## Slide plan / 逐页计划

| No. | Role / 功能 | Main message / 主旨 | Evidence or source / 证据或来源 | Visual / 视觉形式 | Time / 时间 |
| --- | --- | --- | --- | --- | --- |
| 1 | Question / 问题 | The study tests one defined treatment and root-growth relationship. / 本研究检验一个明确的处理与根系生长关系。 | Study objective; no result claim. / 研究目标，不作结果判断。 | One-sentence title and simple study schematic. / 一句话标题和简化研究示意图。 | 0:30 |
| 2 | Context / 背景 | Existing literature motivates the question, but does not answer this experiment. / 既有文献提出研究依据，但不能直接回答本实验。 | Two supplied review articles; exact citations to be added. / 两篇已提供的综述，完整引用待补充。 | Two evidence points and a clearly labeled gap. / 两条证据和明确标注的研究缺口。 | 0:45 |
| 3 | Design / 设计 | The comparison and measurement plan determine what can be inferred. / 比较关系和测量方案决定可作出的推断范围。 | Groups, time points, endpoint definition, and exclusion rules. / 分组、时间点、终点定义和排除规则。 | Experimental timeline and group table. / 实验时间线和分组表。 | 1:00 |
| 4 | Data quality / 数据质量 | The result is interpretable only after the planned quality checks. / 完成计划中的质量检查后，结果才具备解释基础。 | Missingness, outlier rule, measurement QC, and sample count; values pending. / 缺失值、异常值规则、测量质控和样本数，具体数值待补充。 | Compact QC table; avoid a decorative dashboard. / 简洁质控表，避免装饰性仪表盘。 | 0:45 |
| 5 | Main result / 主要结果 | The observed treatment difference, if confirmed, should be reported with uncertainty. / 如果差异得到确认，应同时报告不确定性。 | Raw or summarized measurements, effect estimate, interval, and test; all pending verification. / 原始或汇总测量、效应估计、区间和检验，均待核验。 | Editable plot with units, sample size, uncertainty, and exact caption. / 带单位、样本量、不确定性和完整图注的可编辑图。 | 1:30 |
| 6 | Interpretation / 解释 | The result supports only the interpretation allowed by the design. / 结果只能支持研究设计允许的解释。 | Result plus alternative explanations and relevant literature. / 结果、替代解释和相关文献。 | Claim, evidence, and limit three-column layout. / “主张、证据、限制”三列表格。 | 1:15 |
| 7 | Limits and next step / 限制与下一步 | The unresolved issue is a verification task, not a hidden conclusion. / 尚未解决的问题应写成核验任务，不能暗示为既定结论。 | Missing replication, confounder, or follow-up measurement; specify which one applies. / 缺少重复、混杂因素或后续测量，需明确具体项目。 | Two-item limitation list and a short next-step diagram. / 两项限制和简短的下一步示意图。 | 0:45 |
| 8 | Take-home / 总结 | State one evidence-bounded conclusion and one action. / 给出一个受证据范围约束的结论和一个行动。 | Links to slides 3–7; full references in backup. / 对应第 3–7 页，完整文献放在备用页。 | Three short take-home lines; no new information. / 三条简短结论，不加入新信息。 | 0:30 |

## Claim-evidence audit / 主张与证据核查

| Claim / 主张 | Evidence needed / 所需证据 | Permitted wording before verification / 核验前可用表述 |
| --- | --- | --- |
| The treatment changes root growth. / 处理改变根系生长。 | Defined endpoint, complete group data, effect estimate, uncertainty, and an appropriate analysis. / 明确终点、完整分组数据、效应估计、不确定性和适当分析。 | “We are testing whether the treatment changes root growth.” / “我们正在检验处理是否改变根系生长。” |
| The difference is biologically important. / 差异具有生物学重要性。 | Predefined meaningful threshold or domain benchmark, not only a p-value. / 预先定义的实际意义阈值或领域基准，不能只看 p 值。 | “Practical importance remains to be assessed.” / “实际意义仍需评估。” |
| The treatment causes the difference. / 处理导致差异。 | A design that supports causal attribution and control of relevant confounding. / 支持因果归因并控制相关混杂的研究设计。 | Use comparative wording tied to the observed design. / 使用与观察设计相符的比较性表述。 |

## Rehearsal checks / 演练核查

- Verify that every number on the result slide matches the source table or analysis output. / 核对结果页的每个数字是否与源表或分析输出一致。
- Add the actual sample size, units, uncertainty definition, and statistical method before presenting. / 汇报前补充真实样本量、单位、不确定性定义和统计方法。
- Check that axis labels and legends remain readable in the room or online window. / 检查现场或线上窗口中坐标轴和图例是否可读。
- Replace “supports” or “is associated with” only when the design justifies stronger wording. / 只有研究设计支持时，才把“支持”或“相关”换成更强的表述。
- Keep full citations and a permission record for adapted figures in the backup slides or project notes. / 在备用页或项目记录中保留完整引用和改编图形的许可记录。
