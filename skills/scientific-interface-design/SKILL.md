# Scientific Interface Design / 科研软件界面设计

**Status / 状态:** v0.1.0 draft

## Use / 适用场景

用于科研分析工具、数据浏览器、图表生成器和实验记录界面的需求拆解与评审。

## Boundaries / 边界

不把 Apple 风格或视觉偏好当作科学质量。不改变原始数据来适应界面，不隐藏参数、失败状态、数据来源或不确定性。

## Required inputs / 必需输入

用户任务、数据对象、输入输出、错误状态、权限、可访问性要求、目标平台和可编辑或可导出格式。

## Workflow and output / 工作流程与输出

先画任务流和状态图，再定义数据契约、控件、验证、错误处理和导出。输出页面结构、交互说明、证据和可访问性清单。没有真实用户或数据时，只输出原型级建议。

## Source / 来源

根据用户提供的 Anatomy、界面设计和科研绘图截图整理；具体项目和设计作者待核验。

## English

Design interfaces around scientific tasks, provenance, validation, errors, accessibility, and export. Visual style alone does not establish scientific quality.
