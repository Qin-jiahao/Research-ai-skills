# Literature Search Plan / 文献检索方案

## 中文

根据下面的研究问题，制定一个可复核的文献检索方案。请输出：

1. 核心概念及其同义词；
2. 推荐数据库及选择理由；
3. 布尔检索式；
4. 纳入和排除标准；
5. 需要提取的证据字段；
6. 检索记录表的字段；
7. 可能的检索偏倚和限制。

不要编造数据库中已经存在的文献。检索结果、DOI 和 PMID 需要通过数据库或原文核验。

## English

Develop a reproducible literature search plan for the research question below. Return the core concepts and synonyms, recommended databases with reasons, Boolean queries, inclusion and exclusion criteria, evidence fields, search-log fields, and likely search biases and limitations.

Do not fabricate papers. Search results, DOIs, and PMIDs must be verified against the relevant database or full text.

## Prompt contract / 提示词契约

### 中文

- **使用场景：** 为明确研究问题制定可复核的文献检索和筛选方案。
- **输入要求：** 研究问题、研究对象、时间范围、语言、数据库权限和纳入排除目标。
- **输出要求：** 概念与同义词、数据库选择理由、布尔式、标准、证据字段和检索日志字段。
- **禁止编造：** 不得编造已经检索到的文献、DOI、PMID、期刊指标或检索结果。
- **信息不足：** 先列出研究对象、时间范围、数据库和筛选标准的缺失项，暂不生成确定的检索结果。
- **双语示例：** 完整输入含疾病、干预、结局和年份范围，输出中英文检索式与记录表；信息不足时只有宽泛主题，输出需要补充的概念和数据库。

### English

- **Use case:** Build a reproducible search and screening plan for a defined research question.
- **Required inputs:** Question, population or object, date range, language, database access, and inclusion goals.
- **Expected output:** Concepts and synonyms, database rationale, Boolean queries, criteria, evidence fields, and search-log fields.
- **Fabrication ban:** Do not invent retrieved papers, DOIs, PMIDs, journal metrics, or search results.
- **Missing information:** List missing population, date range, databases, and criteria before producing any definite retrieval claim.
- **Bilingual example:** With disease, intervention, outcome, and date range, return bilingual queries and a log template; with only a broad topic, return missing concepts and database questions.

## Source / 来源

来源于网络和用户提供的文献检索材料，自行整理汇总；不代表已经执行过数据库检索。

Source: online materials and user-provided literature-search material, independently organized. It does not indicate that a database search has been executed.
