# Multi-agent Research Review Workflow / 多角色科研审查工作流

## 中文

### 使用场景

当研究设计、分析计划、论文草稿或科研软件方案需要多个独立角度审查时使用。角色可以覆盖研究设计、统计、代码、图表和写作。

### 输入要求

提供审查对象、证据材料、角色定义、每个角色的独立任务、评价标准、输出格式、冲突处理规则和人工确认节点。

### 输出要求

输出角色意见表、证据链接、共同意见、分歧、待核验事项、行动清单和人工确认记录，并标注每条意见是否实际检查过。

### 禁止编造的内容

不得把角色一致意见写成独立证据，不得虚构角色输出、数据、文献、运行状态、共识或已完成行动。

### 信息不足时的处理方式

先列出缺少的研究设计、数据、角色边界和评价标准。材料不完整时只能提出条件化审查计划，不能给出“多数 Agent 认为可靠”的结论。

### 双语示例

**完整输入：** 提供研究问题、分析计划、数据字典、五个角色的独立任务和评价标准。**预期输出：** 保留统计与写作角色的分歧，并为每条意见链接证据。

**信息不足：** 只有“让五个 Agent 判断方案是否可靠”。**预期处理：** 标记数据、设计、角色边界和评价标准待补充，不生成共识结论。

### 来源说明

来源于网络和用户提供的多角色讨论截图，自行整理汇总；未复制第三方宣传性表述。

## English

### Use case

Use this Prompt when a study design, analysis plan, manuscript, or research-software proposal needs independent perspectives from roles such as design, statistics, code, figures, and writing.

### Required inputs

Provide the review object, evidence, role definitions, independent tasks, evaluation criteria, output format, conflict rules, and human confirmation points.

### Expected output

Return a role-opinion table, evidence links, shared points, disagreements, items to verify, an action list, and human-confirmation notes. Mark whether each opinion was actually checked.

### Fabrication ban

Do not treat role agreement as independent evidence. Do not invent role reports, data, references, execution status, consensus, or completed actions.

### Missing information

List missing design, data, role boundaries, and evaluation criteria first. With incomplete material, return only a conditional review plan and do not claim that most agents found the plan reliable.

### Bilingual example

**Complete input:** Supply the research question, analysis plan, data dictionary, independent tasks for five roles, and evaluation criteria. **Expected output:** Retain disagreements between statistics and writing roles and link every finding to evidence.

**Incomplete input:** Only “ask five agents whether the plan is reliable” is supplied. **Expected handling:** Mark data, design, role boundaries, and criteria as missing and do not generate a consensus conclusion.
