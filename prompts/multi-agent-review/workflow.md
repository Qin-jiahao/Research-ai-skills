# multi-agent-review / 双语工作流

## 中文

请依据我提供的材料执行 multi-agent-review 工作流。先列出缺失信息和证据边界，再输出结构化结果。不得编造数据、文献、运行状态、权限或效果；把待核验内容单独列出。

## English

Apply the multi-agent-review workflow only to the materials I provide. State missing information and evidence boundaries first, then return a structured result. Do not invent data, references, execution status, permissions, or performance claims; list unverifiable items separately.
