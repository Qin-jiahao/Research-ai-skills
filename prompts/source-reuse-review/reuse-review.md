# Open-source Reuse Review / 开源项目复用审查

## 中文

### 使用场景

在科研开发前比较直接使用、二次开发和自行实现三种路径。

### 输入要求

提供科研任务、候选仓库 URL、目标版本、运行环境、数据访问限制和许可证要求。

### 输出要求

输出功能匹配表、维护和依赖风险、许可证义务、三种路径比较、条件化建议和待核验事项，并记录访问日期和证据链接。

### 禁止编造的内容

不得把截图、Star 数、宣传语、评论或未访问页面当作质量、兼容性或许可证证据。

### 信息不足时的处理方式

缺少官方 URL、版本或环境时，列出无法核验的字段，不给出确定的采用建议。

### 双语示例

**完整输入：** 提供两个仓库 URL、目标版本、运行环境和 MIT 许可证限制。**预期输出：** 返回带访问日期的路径比较和许可证风险。

**信息不足：** 只有一个项目名称。**预期处理：** 列出官方 URL、版本、许可证、依赖和数据访问边界待补充。

### 来源说明

来源于网络和用户提供的开源项目复用材料，自行整理汇总；未复制上游代码或文本。

## English

### Use case

Compare direct use, adaptation, and independent implementation before research development.

### Required inputs

Provide the research task, candidate repository URLs, target version, execution environment, data-access limits, and license requirements.

### Expected output

Return a feature-match table, maintenance and dependency risks, license obligations, path comparison, conditional recommendation, and open checks, with access dates and evidence links.

### Fabrication ban

Do not treat screenshots, star counts, promotional language, comments, or unvisited pages as evidence of quality, compatibility, or licensing.

### Missing information

If official URLs, versions, or environment details are missing, list unverifiable fields and avoid a definitive adoption recommendation.

### Bilingual example

**Complete input:** Supply two repository URLs, target versions, an execution environment, and an MIT-only constraint. **Expected output:** Return an access-dated path comparison and license risks.

**Incomplete input:** Only a project name is supplied. **Expected handling:** Mark the official URL, version, license, dependencies, and data-access boundary as missing.

Source: online materials and user-provided open-source reuse material, independently organized. No upstream code or text was copied.
