# Academic Language Polish Workflow / 学术语言润色工作流

## 中文

### 使用场景

当已有论文段落、摘要、图注或审稿回复需要提高自然度和逻辑清晰度，同时必须保留事实、术语、统计结果和作者立场时使用。

### 输入要求

提供原文、目标语言、研究领域、读者、需保留的术语、目标期刊要求和允许的修改范围。

### 输出要求

按“修改稿、主要改动、术语变化、可能改变含义的位置、待作者核对”输出。保留原始数字、引用标识和限定词。

### 禁止编造的内容

不得新增数据、文献、样本信息、因果关系、运行结果、作者观点或未提供的期刊要求。自然度不等于事实正确。

### 信息不足时的处理方式

先列出缺少的原文、目标语言、读者和不可改变的事实。信息补齐前只给出检查清单，不生成新的研究结论。

### 双语示例

**完整输入：** 提供一段 Results 文本、原始统计数值、术语表和目标期刊语言要求。**预期输出：** 给出保留数字和结论强度的修改稿，并列出逐项修改理由。

**信息不足：** 只有“把这段写得更像人”。**预期处理：** 标记原文、目标语言、读者和事实边界待补充，不进行实质改写。

### 来源说明

来源于网络和用户提供的截图，自行整理汇总；未复制第三方原文或宣传语。

## English

### Use case

Use this Prompt when supplied manuscript text, abstracts, captions, or reviewer responses need clearer and more natural academic language while facts, terminology, statistics, and authorial position must remain intact.

### Required inputs

Provide the source text, target language, field, audience, terms to preserve, journal requirements, and allowed edit scope.

### Expected output

Return the revision, major edits, terminology changes, possible meaning changes, and author-verification items. Preserve original numbers, citation markers, and qualifiers.

### Fabrication ban

Do not add data, references, sample information, causal claims, execution results, author opinions, or unstated journal requirements. Naturalness is not proof of correctness.

### Missing information

List missing source text, target language, audience, and non-negotiable facts first. Until they are supplied, return a checklist rather than a new research conclusion.

### Bilingual example

**Complete input:** Supply a Results paragraph, original statistics, a terminology list, and journal language requirements. **Expected output:** Return a revision that preserves numbers and claim strength, with itemized reasons.

**Incomplete input:** Only “make this sound more human” is supplied. **Expected handling:** Mark the source, target language, audience, and evidence boundary as missing and do not perform a substantive rewrite.
