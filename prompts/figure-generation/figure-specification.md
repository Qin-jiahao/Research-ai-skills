# Figure Specification / 科研图形规范

## 中文

根据数据字段、研究问题和目标期刊要求，制定一个可编辑科研图形的规范。请输出：图形目的、推荐图形类型、字段映射、坐标轴和单位、分组与颜色、误差线定义、样本量、统计标记、图注草稿、导出格式和核验清单。

如果输入没有提供单位、误差定义或统计方法，请列为待确认项目。不要把示例数据当作真实数据，也不要直接修改原始数据。

## English

Create a specification for an editable research figure using the supplied data fields, research question, and journal requirements. Return the figure purpose, recommended chart type, field mapping, axes and units, grouping and colors, error-bar definition, sample size, statistical annotations, caption draft, export format, and verification checklist.

If units, error definitions, or statistical methods are missing, list them as open questions. Do not treat example data as real data or modify raw data directly.

## Prompt contract / 提示词契约

### 中文

- **使用场景：** 根据真实数据字段和研究问题制定可编辑科研图形规范。
- **输入要求：** 数据字段、研究问题、目标读者、单位、分组、误差定义、统计方法和期刊格式。
- **输出要求：** 图形目的、图形类型、字段映射、视觉编码、图注、导出规格和核验清单。
- **禁止编造：** 不得新增样本量、显著性、统计结果或修改原始数据。
- **信息不足：** 把缺少的单位、误差和统计方法列为待确认，给出条件化结构方案。
- **双语示例：** 完整输入含数据字典和误差定义，输出可编辑图形规范；信息不足时只有截图，输出待补充清单，不生成结果图。

### English

- **Use case:** Specify an editable research figure from real fields and a research question.
- **Required inputs:** Data fields, question, audience, units, groups, error definition, statistical method, and journal format.
- **Expected output:** Figure purpose and type, field mapping, visual encoding, caption, export specification, and checks.
- **Fabrication ban:** Do not add sample sizes, significance, statistics, or alter raw data.
- **Missing information:** List missing units, error definitions, and methods as open items and give a conditional structural plan.
- **Bilingual example:** With a data dictionary and error definition, return an editable specification; with only a screenshot, return missing fields and no result figure.
