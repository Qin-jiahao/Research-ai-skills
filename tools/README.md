# Tools / 科研工具

## 中文

本目录用于记录值得研究者进一步核验的独立软件、开源项目、MCP 服务和桌面工具。这里的工具不是本仓库自带的 Skill，也不会因为出现在目录中就表示已经安装、测试或推荐。

每条工具记录应包含名称、类型、用途、原始 URL、作者或维护者、许可证、核验日期、测试状态、兼容环境和已知限制。无法确认的字段写 `unknown` 或 `unverified`。

工具的安装、权限、数据访问和安全风险需要在实际使用前单独审查。不要直接运行来源不明的安装脚本。

## English

This directory records independent software, open-source projects, MCP services, and desktop tools that may be useful to researchers. A tool listed here is not a bundled Skill and is not automatically installed, tested, or recommended.

Each record should include the name, type, purpose, original URL, author or maintainer, license, verification date, test status, compatible environments, and known limitations. Use `unknown` or `unverified` when a field cannot be confirmed.

Review installation, permissions, data access, and security before use. Do not run installation scripts from an unverified source.
