# Contributing

## 中文

提交新的 Skill 或 Prompt 时，请说明适用场景、所需输入、预期输出、已知限制和测试案例。不要提交未经授权的第三方原文、个人信息、未公开研究数据或凭空生成的文献和结果。

## English

When contributing a Skill or Prompt, document its use cases, required inputs, expected outputs, known limitations, and test cases. Do not submit unauthorized third-party text, personal information, unpublished research data, fabricated references, or fabricated results.
