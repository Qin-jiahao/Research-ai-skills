# Resource Status / 资源状态

## 中文

状态使用以下词语：

- **Collected**：已收集，来源或内容仍需检查。
- **Reviewed**：已完成结构、来源和边界审查。
- **Tested**：已用记录的案例完成检查；不等于科研结论正确。
- **Released**：已进入版本发布范围。

当前仓库中的新增资源主要为 `Reviewed` 草稿。除根目录发布记录明确列出的内容外，不应把它们视为经过真实数据验证的科研分析工具。外部项目目录中的资源是 `Collected` 或 `Reviewed` 参考，不属于本仓库可安装包。

## English

Status labels are **Collected**, **Reviewed**, **Tested**, and **Released**. Most newly added resources are reviewed drafts. They are not validated research-analysis tools unless a concrete test record says so. External projects listed in the catalog are references, not installable contents of this repository.
