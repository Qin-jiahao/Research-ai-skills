# Resource coverage / 资源覆盖

The machine-readable matrix is [`catalog/resources.json`](../catalog/resources.json). It contains exactly R01–R31. Each record includes status, local path or source URL, and the reason for inclusion or deferral.

机器可读矩阵见 [`catalog/resources.json`](../catalog/resources.json)，包含 R01–R31。每条记录都写明状态、本地路径或来源链接，以及收录或暂缓的原因。

Local `released` records are the repository's own rewritten material. External records remain catalog entries until their upstream license, version, and behavior have been checked.
