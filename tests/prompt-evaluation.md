# Prompt Evaluation / Prompt 评估

## 中文

每个 Prompt 至少使用一个完整案例和一个信息不足案例进行测试。记录输入、预期输出、实际问题和修改版本。重点检查事实保持、输出结构、拒绝编造和双语一致性。

## English

Test every Prompt with at least one complete case and one incomplete-input case. Record the input, expected output, observed problems, and revision version. Check factual preservation, output structure, refusal to fabricate, and bilingual consistency.
