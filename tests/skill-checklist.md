# Skill Checklist / Skill 检查清单

## 中文

- [ ] 是否明确使用场景和任务边界？
- [ ] 是否列出必需输入和缺失信息处理方式？
- [ ] 是否规定稳定、可检查的输出格式？
- [ ] 是否禁止编造数据、文献和结论？
- [ ] 是否包含质量检查和限制说明？
- [ ] 是否有正常案例和信息不足案例？
- [ ] 中文和英文内容是否表达一致？

## English

- [ ] Are the use cases and scope explicit?
- [ ] Are required inputs and missing-information handling documented?
- [ ] Is the output format stable and checkable?
- [ ] Does the Skill prohibit fabricated data, references, and conclusions?
- [ ] Are quality checks and limitations included?
- [ ] Are there both normal and incomplete-input test cases?
- [ ] Do the Chinese and English versions express the same requirements?
